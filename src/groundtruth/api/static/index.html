How it works, in detail

Check whether a photo has been edited.

Upload an image and see what the pixels say. Retrace measures the physical traces a camera leaves behind — and that editing breaks — rather than asking a model to guess. When the original is still recoverable from the file, it shows you that too.

How it works

1

Read the file, not the picture

Timestamps, the software that wrote it, and whether the file really is the format its name claims. A photo taken before the policy started is a problem no matter how authentic it looks.

2

Check the compression history

JPEG compresses on a fixed 8×8 grid. Paste in a region from another photo and it brings its own grid, misaligned with the frame around it.

3

Check the sensor physics

Every sensor leaves a noise signature and every lens bends colour predictably. Edited regions break patterns no editor thinks to preserve.
